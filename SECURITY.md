# Security

Version 0.1.0 is a developer preview, not a security certification.

Please report suspected vulnerabilities privately through the contact page at https://nakaryu.de/kontakt/ before posting exploit details. Identify the repository and version; use synthetic data. Do not send credentials, production exports or customer information. There is no guaranteed response SLA.

These tools do not require external service credentials, collect telemetry, send input to Nakaryu, or initiate network requests. WordPress and other installed components may have their own logging and network behavior. Read the project-specific privacy notes before using real input.
